# Driftpilot working standards

- Prefer existing shared components and typed content accessors.
- Keep components presentational; do not import content data directly into pages or components.
- Preserve a server-first model and introduce client components only for browser-only behavior.
- Keep one primary CTA and preserve automotive-funnel isolation.
- Run lint, typecheck, and build before handoff.
- Use the existing Claude roles for independent review, testing, audit, and content strategy.
